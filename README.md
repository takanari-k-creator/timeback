# 次の一手（仮）

「次、何するんだっけ」をなくすための、高校生向けの予定・空き時間アプリです。ブラウザで開くだけで使えます。

**使うページ：** https://takanari-k-creator.github.io/timeback/

## できること
- **ホーム**：今やること・次の予定、生活リズムの9つの質問から計算した「今日の空き枠」、やることを空き枠に割り当てる案、持ち物チェック
- **カレンダー**：日付ごとの予定の追加・削除
- **時間割**：時間割と、毎日・曜日ごとの持ち物の登録
- **データの保存と引っ越し**：データをファイルに書き出し・読み込み（Python版の `data.json` と同じ形式）

## データについて
- データは、**使っている人のブラウザの中（localStorage）にだけ保存**されます。どこにも送信されません
- 人ごと・端末ごとにデータが分かれます。別の端末で使うときは「ファイルに書き出す」→「ファイルを読み込む」で引っ越せます
- ブラウザの閲覧データを消すと、アプリのデータも消えます。大事なときは書き出しておいてください

## もとのPython版との違い
- Streamlit（Python）版を、HTMLとJavaScriptだけで動くように書き直しました。空き枠の計算と割り当てのルールは同じです
- 写真から時間割を読み取る機能は、APIキーをページに書けないため省きました。時間割は手で入力します
